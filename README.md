# 見積・受発注書類OCR

金属加工部品の見積・受発注業務で日常的に読み込む書類（客先からの見積依頼書・注文書、仕入先からの見積書、図面）を
写真やPDFでアップロードすると、Claudeの画像認識で品番・数量・単価・納期などの項目を自動抽出し、
その場で内容を修正してCSVに出力できる、個人利用向けのシンプルなツールです。

ログイン機能はなく、ブラウザから直接使います。抽出した履歴はブラウザのlocalStorageに保存されます
（サーバー側にデータベースは持ちません）。

## できること

- 書類種別（見積依頼書 / 客先注文書 / 仕入先見積書 / 図面）を選んでファイルをアップロード
- PDF（5ページまで）・JPG・PNG・WEBPに対応、複数ファイルの同時アップロードも可能
- Claudeが書類を読み取り、以下の項目を抽出
  - ヘッダー: 取引先名、担当者名、書類番号、発行日、回答期限・希望納期、見積有効期限、支払条件、通貨、備考
  - 明細: 品番、品名、材質、図面番号、Rev、数量、単位、単価、金額、納期、表面処理、公差、備考
- 抽出結果はその場で編集可能（読み取りmiss・手書き文字などを手動で補正）
- 1件ずつ、または履歴をまとめてCSVダウンロード（Excelで開けるようUTF-8 BOM付き）

## セットアップ

1. Python 3.10以上をインストール
2. 依存パッケージをインストール

   ```bash
   pip install -r requirements.txt
   ```

3. `.env.example` を `.env` にコピーし、Anthropic の APIキーを設定

   ```bash
   cp .env.example .env
   ```

   `.env` を開いて `ANTHROPIC_API_KEY=` に自分のAPIキーを設定してください。
   APIキーは https://console.anthropic.com で発行できます。

4. サーバーを起動

   ```bash
   python app.py
   ```

5. ブラウザで `http://127.0.0.1:5000` を開く

## 使い方

1. 書類種別のタブを選ぶ
2. ファイルをドラッグ＆ドロップ、またはクリックして選択
3. 「この内容を読み取る」を押す
4. 抽出結果が表示されるので、誤りがあれば直接編集する
5. 「履歴に保存」でブラウザに保存、または「この結果をCSV出力」でその場でダウンロード
6. 下部の「履歴」から過去の読み取り結果をまとめてCSV出力できる

## 注意点・制限事項

- 図面のOCRは、表題欄（品番・品名・材質・図面番号・数量など）の読み取りを想定しています。
  寸法線や公差記号を含む図面全体の完全な読み取りは精度が不十分な場合があるため、必ず目視確認してください。
- 数値項目（数量・単価・金額）は文字列として抽出されます。読み取りmiss（誤字・桁ズレ等）がないか必ず確認してください。
- Claude APIの呼び出しには料金が発生します（画像1〜複数枚＋出力トークン分）。
- このツールは「書類を読み取ってデータ化する」ところまでが範囲です。
  仕入先ごとの価格比較、受注・発注管理表、進捗管理といった業務フロー全体の管理は次のフェーズで検討してください
  （このMVPで読み取ったデータをCSVでその管理台帳に取り込む、という繋ぎ方を想定しています）。
